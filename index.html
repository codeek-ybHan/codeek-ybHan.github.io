01소개

경제학·경영학·정보통계학을 바탕으로 가치평가 도구 ValuFlow를 직접 개발·배포하고, 공시 조기경보 AI Agent에서 공시·RAG 데이터를 맡았습니다. 공시 원본 대조와 계산 구조 개선, 사용자 피드백 반영을 통해 재무 이해를 실제 도구로 연결해 왔습니다.

  1. 근거부터 확인

    공시 원본·주석까지 입력값을 직접 검증합니다.

  2. 역할 분리

    계산은 엔진이, 해석은 AI가 — 책임을 나눠 설계합니다.

  3. 배포하고 개선

    직접 배포하고 사용자 의견으로 고쳐 나갑니다.
